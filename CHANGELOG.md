# Changelog

## [1.0.0] - 2026-10-07

### 추가
- curl, Python, TypeScript(Node 18+) 예제: 블로그 글 초안 등록, 카페 글 초안 등록, 글 상태 조회, 연결 계정 조회
- 공개 API OpenAPI 명세 사본 (`docs/openapi.json`)
- 예제 요청 본문 스키마 검증 스크립트 (`scripts/validate_payloads.py`)
- 한국어 README, 영어 README

### Added
- curl, Python and TypeScript (Node 18+) examples: create a blog post draft, create a cafe post draft, check a post's status, read the bound account
- Copy of the public API OpenAPI spec (`docs/openapi.json`)
- Script that validates the example request bodies against the schema (`scripts/validate_payloads.py`)
- Korean and English READMEs
